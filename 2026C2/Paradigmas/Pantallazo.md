# Clasificaciones de Lenguajes de Programación

- Compilado / Interpretado
- Bajo nivel / Alto nivel
- Tipado estático / Tipado dinámico
- Fuertemente tipado / Débilmente tipado

#### Compilado vs Interpretado

| Compilado                                                                | Interpretado                                                                |
| ------------------------------------------------------------------------ | --------------------------------------------------------------------------- |
| Se compila y traduce todo el código a codigo maquina antes de ejecutarse | El código se va traduciendo instruccion por instruccion mientras se ejecuta |
| Cada vez que se modifica debe compilarse otra vez                        | Se puede modificar el codigo y ejecutarse sin un proceso de compilacion     |
| Detecta errores al momento de la compilacion                             | Los errores se detectan durante la ejecucion                                |
| Mas rapidos                                                              | Mas lentos                                                                  |

#### Bajo vs Alto nivel

Cuanto mayor sea el nivel, más legible se vuelve para el humano, cuanto mas bajo es, mas se parece al código de maquina

#### Tipado Estático vs Tipado Dinámico

| Tipado Estático | Tipado Dinámico |
| --- | --- |
| Validaciones de tipos en compilación | Validaciones de tipos en ejecución |
| Generalmente, declaraciones explícitas de tipos | No requiere declaración explícita de tipos |
| Errores se detectan en compilación | Errores se detectan en ejecución |
| Asignación de variables es estática y no puede ser modificada | Asignación de variables es dinámica y puede ser modificada |

# Qué es un Paradigma

Es un marco teorico o disciplina dentro del cual se formulan teorias, leyes y generalizaciones.

## Paradigma de Programación
- Marco teórico que nos permite resolver problemas algoritmicos
- Una forma de pensar / encarar problemas
- **Estilo** de programación

| Paradigmas de Programación |
| --- |
| - **Imperativos** |
|   - Procedural |
|   - Orientado a Objetos |
| - **Declarativo** |
|   - Funcional |
|   - Lógico |

### Paradigmas Imperativos vs Declarativos
Los imperativos describen **cómo** nuestro programa va a hacer algo. Para eso debemos definir secuencias de instrucciones a ejecutar paso a paso.
Los Declarativos describen **qué** hace el programa. No definimos secuencias ni instrucciones.
